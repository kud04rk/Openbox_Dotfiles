# Openbox shortcuts

Press `Super+F1` anywhere to open a searchable rofi popup with all of the shortcuts below.

`Super` = Windows key · `←/→/↑/↓` = arrow keys · `PgUp/PgDn` = Page Up/Page Down

## System keys

| Shortcut | Function |
| --- | --- |
| `Brightness Up` | Increase screen brightness |
| `Brightness Down` | Decrease screen brightness |
| `Volume Up` | Increase volume |
| `Volume Down` | Decrease volume |
| `Volume Mute` | Toggle mute |
| `Media Stop` | Stop playback |
| `Media Play/Pause` | Toggle play/pause |
| `Media Prev` | Previous track |
| `Media Next` | Next track |
| `Calculator` | Open calculator |

## Window switching

| Shortcut | Function |
| --- | --- |
| `Alt+Tab` | Cycle to next window |
| `Alt+Shift+Tab` | Cycle to previous window |
| `Super+Shift+→` | Focus window to the right |
| `Super+Shift+←` | Focus window to the left |
| `Super+Shift+↑` | Focus window above |
| `Super+Shift+↓` | Focus window below |

## Window tiling (snapping)

| Shortcut | Function |
| --- | --- |
| `Super+←` | Snap window to left half of the screen |
| `Super+→` | Snap window to right half of the screen |
| `Super+↑` | Snap window to the top (half width, half height) |
| `Super+↓` | Snap window to the bottom (half width, half height) |

## Desktops

| Shortcut | Function |
| --- | --- |
| `Super+1 … 8` | Switch to desktop 1–8 |
| `Super+Shift+1 … 8` | Send window to desktop 1–8 |

## Windows

| Shortcut | Function |
| --- | --- |
| `Alt+Space` | Window (client) menu |
| `Super+Space` | Openbox root menu |
| `Super+T` | Toggle window decorations |
| `Super+Shift+R` | Toggle visual mode and reconfigure Openbox |
| `Super+F` | Toggle fullscreen |
| `Super+X` | Toggle maximize |
| `Super+Z` | Minimize (iconify) window |
| `Super+C` | Close window |
| `Super+D` | Toggle show desktop |

## Applications

| Shortcut | Function |
| --- | --- |
| `Super+L` | Lock screen |
| `Super+B` | Web browser (Brave) |
| `Super+R` | Application launcher (rofi) |
| `Super+PgUp` | Brightness menu (rofi) |
| `Super+PgDn` | Volume menu (rofi) |
| `Super+F11` | Bluetooth menu |
| `Super+F12` | Network menu |
| `Super+Esc` | Power menu (rofi) |
| `Super+Return` | Terminal |
| `Super+E` | File manager |
| `Super+M` | Music player (rofi) |
| `Super+S` | Text editor (Leafpad) |
| `PrintScreen` | Take screenshot now |
| `Super+PrintScreen` | Screenshot menu (rofi) |
| `Super+F1` | Show the shortcuts popup |

## Mouse

| Shortcut | Function |
| --- | --- |
| `Super+Left drag` | Move window |
| `Super+Right drag` | Resize window |
| `Super+Middle click` | Lower window below others |
| Titlebar `Left drag` | Move window |
| Titlebar `Left double-click` | Toggle maximize |
| Titlebar `scroll up/down` | Shade/unshade window |
| Desktop `scroll up/down` | Previous/next desktop |
| Desktop `right-click` | Openbox root menu |
| Desktop `middle-click` | Window list menu |
